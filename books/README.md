# books 資料夾說明

這個資料夾放「小說本體」。**一本小說 = 一個 `.js` 檔**。

## 加入新小說的步驟

1. 複製 `vesperale.js` 當範本,存成新檔名,例如 `我的小說.js`。
2. 把裡面 `registerBook({...})` 裡的內容改成你自己的小說資料(格式見下方)。
3. 打開 `manifest.js`,把新檔名加進陣列裡:

   ```js
   window.NIGHTREAD_BOOK_FILES = [
     "vesperale.js",
     "我的小說.js"
   ];
   ```

4. 存檔後重新整理 `index.html`,新小說就會出現在書架上。

> 因為瀏覽器沒辦法自己「掃描」資料夾裡有哪些檔案,所以需要 `manifest.js`
> 這份清單告訴程式要載入哪些檔案。只要記得每加一本新書、就在清單裡加一行檔名即可。

## 小說檔案格式

```js
registerBook({
  id: "唯一英數代碼,例如 my-novel",   // 不可跟其他小說重複
  title: "小說標題",
  author: "作者(可留空字串)",
  tagline: "一兩句簡介,顯示在書架卡片上",
  volumes: [
    {
      id: "vol1",              // 卷的代碼
      name: "第一卷·卷名",       // 卷名,顯示在側欄與章節頂部
      chapters: [
        {
          id: "ch01",           // 章節代碼,同一本小說裡不可重複
          num: 1,                // 章節序號(序章可用 -1、番外可用 100 等排序用)
          title: "第一章·標題",
          html: "<p>這裡放章節內文,用 HTML 段落包起來即可。</p><p>第二段…</p>"
        }
      ]
    }
  ]
});
```

- `id`(小說、卷、章節的 id)只要在各自的範圍內不重複即可,不會顯示給讀者看。
- `html` 欄位直接放 HTML,最簡單的作法是每段文字用 `<p>...</p>` 包起來。
- 書架上的「已內建」標籤、無法被使用者從書架刪除,都是因為資料夾小說預設是唯讀的
  (`registerBook` 會自動補上 `builtin: true`)。使用者若想上傳自己的其他書,
  仍可透過首頁的「上傳新書」用 .zip 匯入,那些書會存在瀏覽器本機、和資料夾小說分開管理。
